# ⚔️ HeroGym 

Фитнес-трекер
## 🌟 Ключевой функционал:
1. **Персонаж (RPG):**
   - Интерактивный силуэт/манекен атлета с разделением на мышечные группы (грудь, спина, плечи, руки, пресс, ноги).
   - Уровень (Level) и шкала опыта (XP), растущие от тренировок и закрытия дневника.
   - Силовой тоннаж (Strength).
2. **Питание (БЖУ):**
   - Приёмы пищи по умолчанию: Завтрак, Обед, Ужин + кнопка «+ Приём пищи».
   - Ручной ввод БЖУ в граммах.
   - Автоподсчёт калорий (`Б×4 + Ж×9 + У×4`).
   - Недельный график баланса БЖУ по дням относительно цели.
3. **Тренировки:**
   - Формат записи подходов: `Вес × Повторы × Подходы` (например `60×8×4`).
   - RPE (1-10) привязывается к упражнению целиком с интерактивной подсказкой: *"Насколько тебе было тяжело?"*.
   - Кардио-блок: Название, Время (мин), Темп / Скорость.
   - Переключение вида: **По неделям** (Неделя 5, 6...) и **По датам**.
4. **Интерактивный календарь:**
   - Вызов по тапу с любого экрана.
   - Маркировка дней: точки проведённых тренировок и статуса питания.
   - При выборе дня — подробная сводка: что съедено и какая тренировка выполнена.
5. **Профиль и замеры:**
   - 3 режима калорий: 🔻 Похудение, ⚖️ Поддержание, 🔺 Набор массы (Mifflin-St Jeor под капотом).
   - Правило БЖУ: Белки = 2 г/кг, Жиры = 1 г/кг, Углеводы рассчитываются под цель.
   - Замеры тела (Грудь, Талия, Рука/Бицепс, Ягодицы, Бедро, Икра): две колонки — **«Текущие»** и **«Целевые»** с авто-дельтой.
   - Динамика веса по дням с подсказкой `?` (правила взвешивания утром натощак).

## 📱 Веб-приложение (PWA для iPhone без Mac):
- **Онлайн-версия:** [https://zeker1stkayen-lgtm.github.io/HeroGym/](https://zeker1stkayen-lgtm.github.io/HeroGym/)
- **100% Offline:** Поддержка `ServiceWorker` (`sw.js`) и сохранение всех данных на устройстве (`localStorage`).
- **Адаптировано под iPhone 13 Pro:** Крупные шрифты (16px+), увеличенные области нажатия, темная тема WotLK.
- **Добавление на экран «Домой»:** Открыть в Safari -> кнопка «Поделиться» -> «На экран "Домой"».
